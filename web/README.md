# YouPiper Web (Astro Frontend)

## Purpose
The main user-facing website for YouPiper. Handles video URL analysis, quality format selection, progress display, local agent detection, and fallback downloading.

## Technology
- **Framework**: Astro 5
- **Styling**: Custom CSS / Tailwind
- **TypeScript**

## Dependencies
- Node.js 18+
- npm / pnpm

## How to Run

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build
```
